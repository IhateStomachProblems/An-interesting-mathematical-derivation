### 普遍规范形问题研究 / A Study on the Universal Canonical Form Problem

**Wang YuZhe** · Preprint, 2026-10-06 · [canonicalform.pdf](canonicalform.pdf)

**标题 / Title**：A Study on the Universal Canonical Form Problem: A Framework, Independence Phenomena, Morphism-Class Exchange, and Optimal Involutive Colour Interfaces（普遍规范形问题研究：框架、独立性现象、态射类交换与最优对合色彩接口）

**描述 / Description**：研究问题：对数学对象，是否存在同时满足表示无关、完备、函子性、复合性与可有效计算的规范形？本文不解决此问题，而给出四项贡献：(1) 分离“规范形”名义下常被混同的五项要求并证明其逻辑独立——弱复合性是完备性的自由推论，强复合性是编码与构造族的联合属性；(2) 以完整的古典归属汇编从有限关系结构到相对素图的归约链，并赋予其内在恢复与构造接口；(3) 证明自然性的极性分类定理：结构变换所沿的态射类由其对表示作用的极性（坐标置换 vs 补）精确决定，范围从全同态范畴直到诱导嵌入；(4) 在显式有界的每色有根 gadget 架构内紧解决支撑对合迁移的最小等尺寸色彩接口优化问题：最优阶为 Θ(√log₂q)，以根半径 2 达成，双部载荷架构下领先常数 2 最优。每一结果均注明适用范围与失败边界；分类附录将各命题标注为本文新结果、已知背景或开放问题。
